- "Process" should probably be renamed to "Phase"
- "Skill" might not be the best name for a concept that represents a set of actions or behaviors that can be performed by an agent
- Transcription has NEVER been validated against real speech — every one of the 24 clips in the library is an annotation or filler. Record a session with someone actually talking before trusting the transcript lane or the digest text built from it.
- Whisper hallucinates WORDS on silence, not just annotations: "You" came out of a chunk that was digitally silent at -91 dB. The bracketed-annotation filter cannot catch it and no text rule can. An energy gate would, but its floor has to be swept against a recording containing QUIET speech first — set a shade too high it silently drops the thing it exists to keep.
- Surface per-source speech: `transcript_clip_source` now records which audio source each clip came from, but `segment.transcript` is still one merged string, so MCP says a neutral "Speech:" rather than "Said:" / "Heard:". Needs a DTO field; deliberately not faked from the merged string.
- `FfmpegAudioProducer` (the mic) anchors ONCE and trusts byte arithmetic for the rest of the session, with no contiguity check. `SystemAudioProducer` verifies every callback against its anchor and re-anchors on a hole. If an avfoundation device ever drops samples the whole remainder of a mic recording slides earlier, silently — the same class of bug, unaddressed on the older path.
- Computer-audio self-exclusion is a SNAPSHOT, not a rule: `CATapDescription` resolves pids at tap creation, so an Electron helper that starts playing later cannot be excluded at all. Concretely — playing a past recording in the Library while capturing feeds DeskRAG's own output into the new recording.
- The packaged computer-audio path is untested and cannot be tested without a signing identity: `NSAudioCaptureUsageDescription`, the `extraResources` entry and `mac.binaries` signing for `audio-tap` are all inert on an unsigned build, and a hardened-runtime spawn failure appears at RUN time, never at build time. Verify with `codesign -d --entitlements -`, not by reading the yml.
- No `npm run probe:` script covers computer audio, unlike every other measured surface. A read-only probe that records ten seconds, runs `volumedetect` on the resulting blob and reports the anchor delta against `ax-dump --clock` would make the Phase-0 measurements repeatable instead of one-off.
